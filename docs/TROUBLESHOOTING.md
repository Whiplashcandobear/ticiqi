# 问题与解决方案

这份文档记录开发过程中实际遇到的典型问题、根因、处理方式和验证重点。

| 问题 | 根因 | 解决方案 | 验证重点 |
| --- | --- | --- | --- |
| 长句在底部被挡住 | 当前句区域使用了过于固定的可视高度，底部控制栏没有为长句留出空间 | 当前句保持一个播放单元，显示层动态折行；长句自动移动到视口顶部；横屏控制栏压缩 | 竖屏、横屏分别检查 2 行以上和超长句 |
| 原本一句话被复制产生的换行拆开 | 文档软件的布局换行被误当成段落换行 | 解析器合并句子内部单个硬换行，只保留真正段落和句末边界 | `Today...garden.` 等完整句子仍只占一个播放单元 |
| 横屏高亮消失 | 横屏渲染分支只绘制普通文本，没有复用当前句渲染逻辑 | 横竖屏使用同一套当前句、强调色和字符级高亮渲染 | 横屏暂停和播放时均能看到高亮 |
| 进度条不能拖动 | 进度条只有显示逻辑，没有把比例映射回句子位置 | 增加 `positionForFraction`，将总进度映射为句索引和句内进度 | 拖到中间、句首、句尾后继续播放 |
| 从头开始后一直显示倒计时 | 倒计时状态和播放状态的切换没有形成完整序列 | 用明确的倒计时序列驱动状态，结束后恢复播放并显示第 1 句 | 0 秒、3 秒、5 秒倒计时分别验证 |
| 横屏按钮挡住文本 | 竖屏的大尺寸按钮被直接复用到横屏 | 横屏使用紧凑控制栏，按钮固定较小宽度，文本窗口保留更多高度 | 当前句和上下文不被底部按钮覆盖 |
| 滚动速度数字被裁切 | 选项按钮宽度不足且文字允许被布局压缩 | 选项行可横向滚动，按钮设置最小宽度，文字禁止软换行 | 80、100、120、140、160 等选项完整显示 |
| 固定 WPM 和真实语速不一致 | 单一预设无法反映每个人的停顿和语速 | 加入 60 词校准、播放中 ±5 WPM，以及可选实时语音跟随 | 快读、慢读和识别中断场景都能继续完成 |
| 语音识别偶尔跳到错误句子 | partial result 重复、标点不同或出现公共词 | 统一大小写/标点/弯引号，只在附近窗口匹配，并使用连续结果和覆盖率确认 | 单个 `garden` 等公共词不能跳过多句 |
| 语音识别不可用时无法继续 | 把识别当成唯一播放驱动 | 2 秒无有效结果进入固定 WPM；权限拒绝、设备不支持也回退 | 拒绝麦克风权限后仍可使用固定 WPM |
| 测试任务无法直接运行 | 当前 AGP/Kotlin 组合的 Gradle test worker 存在 classpath 兼容问题 | 使用独立 Kotlin/JUnit 运行器验证纯领域层，同时用 Gradle 验证 Android 编译和 APK | 28 个领域测试通过，`assembleDebug` 通过 |

## 排查顺序

1. 先确认当前模式是固定 WPM 还是实时语音跟随。
2. 如果是实时模式，检查录音权限、系统英文语音服务和相机是否占用麦克风。
3. 如果文本显示不完整，先回到编辑页确认原文是否真的含有段落换行。
4. 如果只是速度不合适，优先使用语速校准，再使用播放中的 ±5 WPM 微调。
5. 如果设备识别不稳定，不要反复重启应用，直接切换固定 WPM 完成演讲。
