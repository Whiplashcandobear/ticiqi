# PRD：英语演讲手机提词器 Android APK

## 文档状态

- 状态：MVP 设计已确认，可进入开发计划阶段
- 日期：2026-09-29
- 技术方向：原生 Android，Kotlin + Jetpack Compose
- 视觉参考：[teleprompter-ui-board.svg](../teleprompter-ui-board.svg)

## 1. 产品概述

这是一个专门服务于“手机 A 录制视频、手机 B 播放英文演讲台本”的离线 Android 提词器。

核心目标不是做复杂的演讲管理工具，而是在录制现场提供一块稳定、清晰、可读、不会误触的提词屏：用户粘贴稿件，选择适合自己语速的 WPM 速度，点击开始，屏幕以歌词播放器一样的方式显示上下文，并高亮当前应读的句子。

产品默认不需要登录、不需要联网、不依赖服务器。稿件和设置保存在本机，应用打开后可以直接继续上次使用。

## 2. 已确认的产品决策

| 项目 | 决策 |
|---|---|
| 播放界面 | A：专注大字版 |
| 上下文密度 | B：标准五句，前两句 + 当前句 + 后两句 |
| 当前句 | 高亮显示，位于视觉中心附近 |
| 速度设置 | 只在播放前选择，不在滚动时放速度滑杆 |
| 速度指标 | WPM，每分钟单词数；同时显示预计总时长 |
| WPM 预设 | 80 / 100 / 120 / 140 / 160，默认 120 |
| 文本粘贴 | C：纯文本和富文本都支持；格式无法识别时降级为纯文本 |
| 必须保留 | 换行、空行、段落、缩进、原有文本顺序 |
| 富文本范围 | 尽量保留粗体、斜体、文字颜色和标题层级；不保证复制来源的所有样式 |
| 屏幕方向 | 默认竖屏；播放页提供横竖屏切换按钮 |
| 背景 | 默认深色，可一键切换浅色 |
| 字体颜色 | 晨蓝（默认）、暖黄、薄荷绿 |
| 技术方案 | Kotlin + Jetpack Compose 原生 Android |
| 数据与网络 | 离线优先，无登录、无服务器、无网络权限需求 |

## 3. 目标与成功标准

### 3.1 产品目标

- 让用户在 1 分钟内完成“粘贴稿件 → 选择速度 → 开始提词”。
- 录制过程中一眼找到当前句，同时保留足够上下文，不需要频繁暂停找稿。
- 让用户用量化的 WPM 选择速度，而不是依赖模糊的“快/慢”滑杆。
- 在黑色和白色背景、竖屏和横屏下都保持清晰可读。
- 不因动画、网络、登录或复杂操作影响现场录制。

### 3.2 MVP 成功标准

- 新用户从首页到开始滚动不超过 4 个主要操作。
- 1000 英文单词稿件在中端 Android 手机上滚动稳定，无明显跳帧或位置漂移。
- 用户可以在 10 秒内完成背景、字号、横竖屏和字体颜色调整。
- 粘贴含有多段落的文本后，换行和空行在播放页仍然可辨认。
- WPM 预计时长与实际滚动时长误差不超过 5%。
- 播放时屏幕不会自动熄灭，暂停后可以从当前位置继续。
- 应用在断网情况下可以完成全部 MVP 流程。

## 4. 用户与核心场景

### 4.1 目标用户

需要用手机录制英语演讲、课程展示、面试陈述或短视频口播，并且希望通过第二台手机阅读台本的人。

### 4.2 核心场景

用户提前把英文稿件复制到手机 B，打开提词器，点击“+ 新建台本”，粘贴内容，确认段落没有乱掉，选择 120 WPM 或其他预设，设置字号和背景，点击“开始提词”。倒计时结束后，当前句在屏幕中间高亮显示，前后句降低对比度但仍然可读，文本按设定速度平滑向上移动。用户可以暂停、继续、切换横竖屏或切换背景，但不会误碰到复杂的速度调节控件。

## 5. 产品范围

### 5.1 MVP 包含

- 本地台本新建、编辑、保存、删除和最近使用列表。
- 复制/粘贴文本。
- 保留纯文本换行、空行、段落和缩进。
- 尽力识别并保留粗体、斜体、文字颜色和标题层级。
- 英文单词数统计。
- 80 / 100 / 120 / 140 / 160 WPM 速度预设。
- 按单词数计算预计总时长。
- 3 秒、5 秒、10 秒倒计时及关闭选项。
- 标准五句歌词式上下文。
- 当前句高亮。
- 深色/浅色背景切换。
- 晨蓝/暖黄/薄荷绿三种强调色。
- 小/中/大/特大字号。
- 默认竖屏与手动横屏切换。
- 暂停、继续、从头开始、继续上次位置。
- 播放时保持屏幕常亮。
- 本地草稿自动保存和异常退出后的恢复。

### 5.2 MVP 不包含

- 用户注册、账号同步和云端备份。
- 多设备同步。
- 语音识别、自动纠错、AI 改稿、翻译或发音评分。
- 摄像头录制功能；录制由另一台手机完成。
- 播放中实时拖动速度滑杆。
- 复杂的 Word 排版编辑器。
- 自定义字体文件导入。
- 多人协作、评论、版本管理。
- 广告、付费墙和联网统计。

## 6. 页面与交互设计

### 6.1 首页

视觉：参考样式板中的浅色蓝白界面，蓝色主按钮，白色台本卡片，避免大面积渐变和装饰性图标。

组件：

- 顶部标题“演讲提词器”。
- 主按钮“开始提词”，有最近台本时直接打开最近台本的播放准备页；没有台本时引导新建。
- 次级入口“新建台本”和“播放设置”。
- 最近台本列表：标题、单词数、预计时长、最近修改时间。
- 台本卡片提供打开、重命名、删除操作；删除前需要确认。

### 6.2 编辑台本页

组件：

- 标题输入框，默认使用“未命名演讲”。
- 大型文本编辑区，支持粘贴和继续编辑。
- “＋ 粘贴内容”快捷按钮，点击后读取系统剪贴板。
- 粘贴后立即显示字数、单词数和预计时长。
- 内容预览区保留段落间距，避免把所有段落压成一整块。
- “清空”操作必须二次确认，并提供撤销机会。
- 底部主按钮“保存并开始”。

文本规则：

- 原始换行和空行必须保留。
- 连续空行最多折叠为 2 个视觉空行，避免极端复制内容撑爆播放页；原始内容仍然保存在文档中。
- 前导空格和缩进默认保留，但在播放页最多显示 4 个等宽空格宽度，防止内容偏离屏幕。
- 粗体、斜体、文字颜色和标题样式尽力保留；不支持的字体、复杂表格、图片和嵌入对象转为纯文本。
- 粘贴来源没有富文本时，使用纯文本路径，不改变字符顺序。

### 6.3 播放设置页

设置项按“影响阅读速度 → 影响阅读清晰度 → 其他行为”的顺序排列。

1. 滚动速度：80 / 100 / 120 / 140 / 160 WPM
2. 预计时长：根据当前稿件单词数实时计算
3. 字号：小 / 中 / 大 / 特大
4. 字体颜色：晨蓝 / 暖黄 / 薄荷绿
5. 背景：深色 / 浅色
6. 倒计时：关闭 / 3 秒 / 5 秒 / 10 秒
7. 初始方向：竖屏 / 横屏；默认竖屏
8. 上下文：固定为标准五句，不在 MVP 中增加复杂配置

### 6.4 播放页

默认状态：竖屏、深色背景、晨蓝高亮、120 WPM、5 秒倒计时、标准五句。

内容布局：

- 顶部：倒计时或已播放时间、当前 WPM、横竖屏状态。
- 中部：歌词式文本窗口；当前句位于中心阅读区。
- 当前句：使用高亮背景块 + 高亮文字颜色双重强调，不单靠颜色传递状态。
- 上下文：前两句和后两句降低透明度，但保持至少可读对比度。
- 底部：进度条、当前段落/总段落、预计剩余时间。
- 控制栏：暂停/继续为唯一主按钮；字号、背景、字体颜色、方向放在“更多”面板中。

播放操作：

- 点击暂停后，文本停止移动，按钮变为“继续”。
- 点击继续后，从相同句子和相同进度继续，不重新倒计时。
- 点击“从头开始”需要确认；确认后回到第 1 句并重新执行倒计时。
- 横竖屏切换只改变布局方向，不改变当前句、滚动位置、速度或主题。
- 背景和字体颜色切换只改变视觉主题，不重置播放状态。
- 播放期间屏幕保持常亮；退出播放页或暂停超过 5 分钟后释放常亮锁。

## 7. 速度与滚动算法

### 7.1 WPM 定义

WPM = 每分钟英文单词数。单词统计使用以下规则：

- 连续英文字母计为一个单词。
- 带撇号和连字符的词，例如 `don't`、`well-known`，整体计为一个单词。
- 纯数字不计入英文单词数，但保留在稿件中。
- 连续空格、换行和标点不计数。

预计总时长：

```text
estimatedSeconds = ceil(wordCount / selectedWpm * 60)
```

例如：1024 个单词在 120 WPM 下预计为 512 秒，即 08:32。

### 7.2 句子分割

- 优先按用户手动换行形成段落边界。
- 段落内部按 `.`, `?`, `!` 及其后面的空格或换行分句。
- 缩写中的句点，例如 `Mr.`、`e.g.`，不作为强制句子边界。
- 无法可靠分句时，保留原段落作为一个文本单元，不删除任何字符。

### 7.3 平滑滚动

每个文本单元的理论展示时间：

```text
segmentSeconds = segmentWordCount / selectedWpm * 60
```

为了避免很短句子瞬间掠过，实际时间使用：

```text
actualSegmentSeconds = max(segmentSeconds, 1.5)
```

句子切换前后使用 150–250ms 的位置过渡；不使用跳跃式瞬移。用户暂停时保存当前文本单元索引和单元内进度比例。

## 8. 视觉与交互规范

### 8.1 颜色令牌

| 用途 | 深色模式 | 浅色模式 |
|---|---|---|
| 背景 | `#070B12` | `#F7F9FC` |
| 主文本 | `#F4F7FB` | `#14233D` |
| 次文本 | `#94A2B5` | `#55708F` |
| 晨蓝 | `#65C8FF` | `#1459B7` |
| 暖黄 | `#FFD76A` | `#8B5A00` |
| 薄荷绿 | `#71E1BC` | `#0C6B54` |
| 主按钮 | `#2F80ED` | `#2F80ED` |
| 分割线 | `#263344` | `#DCE6F2` |

所有主题组合需要分别验证对比度；次文本只能用于上下文，不用于错误或关键状态。

### 8.2 字号

- 编辑正文默认 16sp。
- 播放页字号预设：28sp / 32sp / 36sp / 42sp。
- 竖屏默认 36sp，横屏默认 32sp，用户可调整。
- 行高使用字号的 1.35–1.5 倍。
- 不使用过细字重；当前句使用 600–700 字重。

### 8.3 触控与无障碍

- Android 主要点击目标不小于 48dp。
- 图标按钮必须有可读的无障碍描述。
- 颜色不是唯一状态提示，当前句同时使用高亮背景和字号/字重变化。
- 状态栏、刘海区、导航栏和手势区域留出安全边距。
- 支持系统字体放大；字号放大后不截断当前句。
- 尊重系统的减少动画设置。

## 9. 技术设计

### 9.1 技术栈

- Kotlin
- Jetpack Compose + Material 3
- Navigation Compose
- SharedPreferences + `org.json`：保存台本、播放位置和全局显示设置
- Android Clipboard API：读取纯文本和可用的富文本剪贴板内容
- Android Activity 屏幕方向 API：手动切换竖屏/横屏
- `FLAG_KEEP_SCREEN_ON`：播放期间保持亮屏
- JUnit + Compose UI Test + Android Instrumentation Test

### 9.2 数据模型

`ScriptDocument`：

- `id: Long`
- `title: String`
- `rawText: String`
- `formattedBlocks: List<FormattedBlock>` 的序列化内容
- `wordCount: Int`
- `createdAt: Long`
- `updatedAt: Long`
- `lastPlaybackUnit: Int`
- `lastPlaybackProgress: Float`

`FormattedBlock`：

- `type: Paragraph | BlankLine`
- `runs: List<TextRun>`

`TextRun`：

- `text: String`
- `bold: Boolean`
- `italic: Boolean`
- `foregroundToken: AccentColor?`
- `headingLevel: Int?`

不支持的富文本属性不进入数据模型；原始纯文本始终保留，确保格式降级时仍可恢复内容。

### 9.3 分层边界

- `domain`：单词统计、分句、WPM、播放状态，不依赖 Android UI。
- `data`：SharedPreferences、`org.json`、剪贴板转换和本地序列化。
- `presentation`：Compose 页面、状态、主题和方向切换。
- `playback`：滚动时钟、单元窗口、暂停/继续和剩余时间。

## 11. 错误与边界处理

- 空稿件：禁止开始播放，提示“请先粘贴或输入台本内容”。
- 单词数为 0 但存在符号：按 0 单词处理，显示“无法计算预计时长”。
- 极短稿件：仍使用标准五句窗口，缺少的上下文位置不显示虚构文本。
- 极长稿件：MVP 目标支持至少 10,000 个英文单词；超过后提示可能影响编辑性能，但允许保存。
- 剪贴板无权限或读取失败：保留手动输入路径，并显示“无法读取剪贴板，请直接粘贴或输入”。
- 屏幕旋转期间：锁定当前播放状态，重建 UI 后恢复单元索引和进度比例。
- 删除台本：二次确认；删除后不可恢复，但不影响其他台本。
